# HYPNOGEN Web

Générateur hypnagogique pour smartphone (iPhone et Android) : son binaural sur porteuse 200 Hz
et flash plein écran synchronisés sur une phase de battement commune.

- 11 séances à profil (moteur identique au firmware HYPNOGEN Nano ESP32), toutes sous 14 Hz.
- Mode PROFIL ou MANUEL, durée 10 à 60 min.
- Calage de latence en millisecondes, mémorisé par sortie audio (filaire, casques Bluetooth).
- Avertissement de sécurité obligatoire avant la première séance.

Page unique : `index.html`. Nécessite HTTPS pour le maintien de l'écran allumé (Wake Lock).

**Avertissement** : lumière clignotante rythmée, contre-indiquée en cas d'épilepsie ou de
photosensibilité. Ce n'est pas un dispositif médical.
